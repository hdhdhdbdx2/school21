# Наша команда

Лид — `cantonim`.  
Участники — `cantonim` и `zandrama`.  
Общая ветка — `develop`.

| Участок | Участник | Когда покажет первую работающую часть |
| --- | --- | --- |
| Лид и чтение | `cantonim` | До объединения показывает чтение каталога и баланса |
| Правила и тесты | `zandrama` | До объединения показывает тесты расчёта стоимости и отказа при нехватке коинов |
| Данные | `cantonim` | До общей проверки показывает запись заказа, списание коинов и уменьшение остатка |
| Действия с заказом | `zandrama` | На общей проверке показывает вызов `create_order` и ответ при отказе |

Изменения объединяет `cantonim` через Merge Request в `develop`.
