# Конверт E4

Сдаваемый профиль: E4

## Условие

Вариант E4 «Скидка за количество» из `envelopes/E4.md`. Ветку используют, если платформа выдала этот конверт.

При покупке от трёх единиц итоговая стоимость составляет 90% обычной цены заказа с округлением вниз. Три набора стикеров по 51 коину стоят 153 в base и 137 в E4. При отмене заказа клиент получает именно списанную сумму.
