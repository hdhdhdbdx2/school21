# Конверт E2

Сдаваемый профиль: E2

## Условие

Вариант E2 «Не больше двух за раз» из `envelopes/E2.md`. Ветку используют, если платформа выдала этот конверт.

В одном заказе разрешено не больше двух единиц. Персональный лимит на общее количество сохраняется. Заказ трёх наборов стикеров проходит в base, а в E2 получает `USER_LIMIT_EXCEEDED`. Заказ двух проходит. Два заказа по две единицы и ещё одна единица укладываются в общий лимит 5.
