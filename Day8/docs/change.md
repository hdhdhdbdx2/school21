# Конверт E1

Сдаваемый профиль: E1

## Условие

Вариант E1 «Несгораемый остаток» из `envelopes/E1.md`. Ветку используют, если платформа выдала этот конверт.

Покупка допустима, если после списания остаётся не меньше 50 коинов. Ровно 50 допустимо. При цене бутылки 150 базовый вариант принимает заказ с балансом 180. E1 отклоняет его с `INSUFFICIENT_COINS`. При балансе 200 E1 принимает заказ и оставляет 50.
