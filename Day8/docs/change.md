# Конверт

Сдаваемый профиль: base

## Условие

Номер выданного команде конверта пока не указан. Для разбора беру пример E1 из `envelopes/E1.md`. По этому правилу после покупки должно остаться не меньше 50 коинов. При балансе 180 и цене бутылки 150 базовый вариант оформляет заказ, а E1 возвращает `INSUFFICIENT_COINS`. При балансе 200 E1 разрешает покупку.

## Что проверяю до изменения

Правило баланса находится в `src/domain.py`, в функции `purchase_error`. В варианте E1 меняется последний шаг проверки. В `testing/test_orders.py` нужны два случая на границе и проверка неизменности базы при отказе. Схемы и SQL используют ту же стоимость заказа.

## Результат

В основной ветке проекта оставлено базовое правило `balance >= total`, пока команда не сверит номер конверта на платформе. Ветка `task6-E1` содержит отдельно подготовленный вариант E1 для сравнения.

```bash
python3 -m pytest -q
python3 checks/acceptance.py --project . --profile base
```

Прошли 6 тестов. Приёмка вернула `PASS — профиль base, вызовов инструментов: 50`.
