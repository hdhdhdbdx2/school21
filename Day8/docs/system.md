# Паспорт Лавки

Профиль правил: base

## Что делает сервер

По контракту Лавка показывает каталог, цену и остатки отдельного товара, баланс участника и статус заказа. Вызовы чтения сохраняют данные в прежнем состоянии. При покупке сервер создаёт заказ, списывает коины и уменьшает остаток. При отмене он возвращает товар и коины один раз. Подтверждение выдачи меняет только статус заказа.

## Границы

Лавка работает локально с учебными пользователями, заранее внесёнными в базу. Клиент передаёт `user_id`. Сервер проверяет, есть ли такой пользователь, без проверки его личности. Настоящие платежи, доставка и изменение каталога через MCP не поддерживаются.

## Путь запроса

Клиент → имя инструмента → функция обработчика → правило, если нужно → метод хранения → ответ.
